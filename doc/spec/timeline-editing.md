# Direct timeline editing

Issue #28. `TimelineEdits.apply` / `Apply` takes a project snapshot, an `EditPlan`, a clip ID (or null for the full take), and one command. It returns a replacement snapshot and the undo label, or inline refusal copy. Preview and commit replay the same command with the same input; only a changed snapshot needs an undo step. No command performs I/O or deletes an asset. Successful changes promote the snapshot to schema v6.

- A placement anchors in source seconds. On the Edited axis call `TimelineItems.sourceAnchor` / `SourceAnchor` before building a command. On Source, a drop can land in a cut; `dropHint` / `DropHint` provides its guide copy. The reducer rounds written time values on the plan's sample grid, including relative audio, fade and keyframe times.
- Word-covering effects, zooms and footage keep a source range. Cuts remove the covered moments without changing the saved range. The layout projects kept intervals and cut notches; a completely covered cut leaves a hidden marker. Companion footage consumes the surviving edited length at 1×. If its file ends first, its visible span is shortened and reports why.
- Sounds and music segments keep their played length on the edited clock. A cut anchor maps to the seam, including when its story part changes order. These items can play across part joins. An unedited music bed has a virtual segment with the track ID; the first edit materialises the segment in the same undo step.
- A word-covering placement move or trim must stay in one story part. Trimming speech changes its word IDs without removing placed items, so items hidden by that trim are available when the speech is restored. Speech edits protect lip-sync windows. Split All at a word boundary creates another part, using each side's playable source edge when the boundary lies in a pause.
- Item identities distinguish effects, footage, motion cues, music, clips and parts. Multi-item commands use the first selection item as the reference anchor. The layout reports a lane and sub-row in the eight-lane order, edited and display-axis intervals, the owning part, hidden markers, and typed snap targets. Playhead time is optional and uses the display axis.
