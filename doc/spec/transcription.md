# Transcription

Status: normative for M1 (0.1.0). Applies to the macOS app (`VoxClipCore`, `VoxClipMedia`, `VoxClip`, `voxclip-cli`) and the Windows app (`VoxClip.Core`, `VoxClip.Media`, `VoxClip.App`, `VoxClip.Cli`).

This spec turns a source video into an immutable list of timed words. It covers:

- the engines, with their requests and responses;
- the assembly of engine tokens into words;
- language routing;
- the model catalogue and downloads;
- progress, cancellation and caching.

## 1. Goals and non-goals

Goals:

1. Every engine produces the same `TimedWord` list on the source presentation timeline, accurate enough to cut between words: median boundary error at most 50 ms after refinement.
2. Fillers are visible. A verbatim engine emits them as words. For an engine that drops them, audible sound in the gaps becomes an `unlabeledSpeech` item that "Cut fillers" can remove.
3. Estonian and English, often mixed, work well. Estonian runs on device on the TalTech verbatim Whisper fine-tune, or in the cloud on ElevenLabs Scribe v2.
4. Nothing leaves the device unless the user chose ElevenLabs, and then only the audio track. Local never silently becomes cloud.
5. Raw engine results are cached per source, so a paid transcription is not repeated by accident.

Non-goals for v1:

- Live transcription while recording. Recording arrives in M2, and batch transcription of the final file stays the source of truth.
- sherpa-onnx, Parakeet, WhisperKit, FluidAudio, and OpenAI or xAI speech-to-text. sherpa-onnx is excluded because its macOS static build links GPL espeak-ng.
- Translation, diarization on local engines, and forced alignment.

## 2. Engines in v1

The engine ids below are the values of `transcript.engine.id` in the project schema, `engines[].id` and `models[].engine` in the catalogue, and the cache file names (14.1). The CLI accepts the aliases `whisper` and `apple` (15).

| Engine id | Platforms | Kind | Languages | `timing` | Verbatim | Needs |
|---|---|---|---|---|---|---|
| `elevenlabs` | macOS, Windows | cloud | 90+, auto-detect | `native` | yes | the user's ElevenLabs key with the `speech_to_text` permission |
| `whispercpp` | macOS: whisper.cpp 1.9.5 xcframework (Metal). Windows: Whisper.net 1.9.1, which wraps whisper.cpp 1.8.5 (CPU or Vulkan) | local | per model (catalogue) | `dtw` (`tokenGrouped` with DTW off) | per model; `false` in v1 (9.9) | a catalogue model plus Silero VAD |
| `apple-speech` | macOS 26+ | system | `SpeechTranscriber.supportedLocales` at runtime (45 on macOS 27.0.1; no Estonian) | `runGrouped` | no | OS speech assets via `AssetInventory` |

Here `verbatim` means "keeps hesitation fillers as words". It decides whether the unlabeled-speech detector runs (7.5). The value per model lives in `shared/catalog/transcription-models.json` and overrides the engine value.

Module placement follows `doc/architecture.md`:

- The ElevenLabs client and the pure parts (`WordAssembler`, the import post-process, routing, cache keys) are in `VoxClipCore` / `VoxClip.Core`.
- The whisper and Apple engines are in `VoxClipMedia` / `VoxClip.Media`, next to audio extraction.

## 3. Data types

All times are seconds, as IEEE-754 doubles, on the **source presentation timeline**: the container timeline after edit lists, with encoder priming removed. Source word times never change after import.

### 3.1 Transcript and TimedWord (stored in the project)

These are exactly `shared/schemas/project.schema.json` (`$defs/transcript`) and `timed-word.schema.json`. Both have `additionalProperties: false`, and every field is written, with `null` for absent optional values. Engine metadata that is not listed here stays in the cache entry (14.2).

## 4. Audio input contract

Before an engine runs, the media layer extracts the first enabled audio track in one streaming pass into `<data>/Cache/<contentKey>/` (`doc/architecture.md` §8.2):

1. **`audio-16k.wav`**: RIFF WAVE, 16-bit signed little-endian PCM, mono, 16 000 Hz, exactly `round(durationSeconds × 16000)` samples (trim or zero-pad). Sample 0 is at source presentation time `timelineStart`.
   - Downmix is an equal-weight average of the channels: on macOS `AVAudioConverter` with `downmix = true`, on Windows FFmpeg `swr` to mono.
   - Float to integer conversion is `Int16(clamp(x, -1, 1) × 32767)`, rounded to nearest with ties away from zero.
2. **Decoded analysis audio** at the source rate and channel count, used for tighten, refine and unlabeled-speech detection (7.2). This is the same decoded audio the editing spec uses. If decoding fails, the post-process runs without audio and `refined = false`.

Each engine reads `audio-16k.wav`:

| Engine | Input |
|---|---|
| `elevenlabs` | the WAV file as is (8.1) |
| `whispercpp` | the samples as Float32 (`s16 / 32768`), level-normalised in memory (9.3) |
| `apple-speech` | a CAF file converted to `SpeechAnalyzer.bestAvailableAudioFormat(compatibleWith:considering:)` (10.4) |

Upload audio is PCM, never AAC or M4A, so decoder priming cannot shift word times. Resampling does not have to match bit for bit between macOS and Windows. The engines are not bit-exact anyway, and refinement uses the decoded analysis audio.

Adapters report token times on the **engine input timeline**, where 0 is sample 0 of `audio-16k.wav`. `WordAssembler` adds `timelineStart`, so `RawWord` times are on the source timeline, as `editing.md` §5.0 requires.

## 5. Pipeline overview

```
source media
  └─ AudioExtractor ──► audio-16k.wav + decoded analysis audio                   (section 4)
       └─ Router picks a TranscriptionPlan                                        (section 11)
            └─ Readiness: key / model download / Apple assets                     (sections 10, 12)
                 └─ Cache lookup <data>/Cache/<contentKey>/transcripts/… ── hit ──┐  (section 14)
                      └─ Transcriber.transcribe ─► RawTranscript ─► cache write  │
                                                    ◄─────────────────────────────┘
                           WordAssembler.group(tokens, rule) + timelineStart      (section 6)
                                                    │  [RawWord]
                           import post-process (editing.md §5)                    (section 7)
                             cleanWords → tightenIntoSound (gapless timings) → refineWordBoundaries
                             → findUnlabeledSpeech (non-verbatim) → ids w1..wN → pauses
                                                    │
                                    Transcript ─► project file (transcript)
```

`TranscriptionService` in Core coordinates a job. It owns one job per project, the job queue (13.4), progress aggregation and the cache. Engines contain no UI code. The import post-process runs once. Reopening a project never reruns it (`editing.md` §5).

## 6. WordAssembler: RawToken to RawWord

`WordAssembler.group(tokens, rule, timelineStart) -> [RawWord]` is pure, deterministic and shared by every engine. It must give identical output in Swift and C# on the fixtures in 16.1.

```swift
public struct GroupingRule: Codable, Hashable, Sendable {
    public enum End: String, Codable, Sendable { case lastToken, nextWordStart }
    public enum Conf: String, Codable, Sendable { case single, mean, min }
    public var end: End
    public var conf: Conf
    public var bracketEvents: Bool      // whisper: "[laughs]" / "(applause)" words become events
}
// elevenlabs: (.lastToken, .single, false)   apple-speech: (.lastToken, .min, false)   whispercpp: (.nextWordStart, .mean, true)
```

Algorithm:

```
drafts = []
for t in tokens (in order):
    newWord = drafts.isEmpty || !t.joinsPrevious || t.group != cur.group || t.kind == .event || cur.kind == .event
    if newWord: drafts.append(Draft(text: t.text, tokens: [t], group: t.group, kind: t.kind ?? .word))
    else:       cur.text += t.text; cur.tokens.append(t)

for each draft d:
    d.start   = first non-nil token start in d.tokens (nil if none)
    d.lastEnd = last non-nil token end in d.tokens
    d.conf    = .single: d.tokens[0].conf | .mean: mean of non-nil confs | .min: min of non-nil confs (nil if none)
    d.speaker = d.tokens[0].speaker

isPunct(d) = d.text matches \A\p{P}+\z                  // the same test cleanWords uses
for i, d in drafts:
    if rule.end == .lastToken: d.end = d.lastEnd
    else:                                                // .nextWordStart
        n = the next draft after i in the same group that is not isPunct and has a start
        d.end = n?.start ?? d.lastEnd
        if d.start != nil && d.end != nil: d.end = max(d.end, d.start + 0.04)   // MIN_WORD

if rule.bracketEvents: apply the event rules below

emit RawWord(text: d.text, start: d.start + timelineStart, end: d.end + timelineStart,
             conf: clamp01(d.conf), speaker: d.speaker, kind: d.kind)            // nil stays nil
```

Bracket events (whisper only). Whisper writes non-speech as `[laughs]`, `(applause)`, `♪` or `[BLANK_AUDIO]`. The rules, in order:

1. **Merge.** A draft that starts with `[` or `(` and has no matching closer absorbs the following drafts of the same group, joined with one space, until a draft contains the closer. It absorbs at most 6 drafts. The merged draft runs from the first start to the last end.
2. **Mark.** A draft whose whole text matches `\A[\[(].*[\])]\z`, or is only `♪`/`♫` and whitespace, is an event.
3. **Drop.** Remove the event if its letters, lowercased, are one of `blankaudio`, `silence`, `nospeech`, `music` or `inaudible`, or if it is only `♪`/`♫`. These are hallucination-prone and give nothing to cut.
4. **Keep.** Otherwise set `kind = .event` and keep the text as written, for example `(laughs)`.

A word with no timed token keeps `start = nil` and is dropped by `cleanWords`. Adapters should not emit untimed text.

## 7. Import post-process (restated from `editing.md` §5)

Input: `[RawWord]`, the decoded analysis audio or none, and `timing` and `verbatim` from the `RawTranscript`. Output: `[TimedWord]`, the pause threshold and the pauses.

Constants:

| Name | Value |
|---|---|
| `FRAME_SECONDS` | 0.01 |
| `MIN_WORD` | 0.04 s |
| `BRIDGE_FRAMES` | 2 |
| `TIGHTEN_MIN_SILENT_FRAMES` | 7 (70 ms) |
| `TIGHTEN_SPLIT_FRAMES` | 15 (a quiet stretch this long splits sound islands) |
| `UNLABELED_MIN_GAP` | 0.25 s |
| `UNLABELED_MIN_FRAMES` | 10 (100 ms) |
| `UNLABELED_PEAK_FACTOR` | 0.25 |
| `UNLABELED_TEXT` | `…` (U+2026) |
| Gapless timings | `runGrouped`, `tokenGrouped`, `dtw` |
| Pause threshold | 0.8 s when `refined`, 1.0 s when not |

### 7.1 cleanWords

For each raw word, in order:

1. Set `kind` to `event` if the raw kind is `event`, else `word`. Set `text` to the NFC-normalised, JS-trimmed raw text. Skip the word if `text` is empty.
2. If `kind == word` and the text is punctuation only (`\A\p{P}+\z`):
   - If it is only opening punctuation (`\A[\p{Ps}\p{Pi}¿¡]+\z`), hold it as a prefix for the next word.
   - Otherwise append it to the previous output item, if that item is a word. Do not extend that item's `end`.
   - Skip it in both cases.
3. Skip the word unless `start` and `end` are finite, `start >= 0` and `end > start`.
4. Keep `conf` only if it is finite and in [0, 1]; otherwise set it to nil.
5. Emit `{text: prefix + text (words only), start, end, conf, kind, speaker}`. Clear the prefix after a word.

Sort the output by `start`, keeping the original order for ties. Then set `rawStart = start`, `rawEnd = end`, and `timing` to the transcript timing.

### 7.2 Level analysis (shared by 7.3 to 7.5)

This is an exact port of `wordBoundaries.ts:28-50`:

```
frameSize   = max(1, jsRound(rate * 0.01));  frameLength = frameSize / rate
frames      = floor(audio.length / frameSize)
if no items, or frames < 10, or channels == 0: no analysis (skip 7.3 to 7.5)
level[f]    = Float32( sqrt( Σ_channels Σ_samples x² / (frameSize * channels) ) )
frameAt(t)  = clamp(floor(t / frameLength), 0, frames - 1)
quietest    = sortAscending(level)[floor(frames * 0.1)]
speechLevel = median (index floor(n/2) after an ascending sort) of the concatenated
              level[frameAt(w.start) ... frameAt(w.end)] over all items
threshold   = max(quietest * 2, speechLevel * 0.08);  if !(threshold > 0): no analysis
audible(f)  = level[f] >= threshold
```

### 7.3 Tighten into sound (only for gapless timings)

Apple runs and whisper word ends are back to back with no gaps, so the first word after a pause absorbs the silence. Third parties measured Apple's typical boundary error at 106–125 ms. This is `editing.md` §5.5, copied verbatim:

```
tightenIntoSound(items, audio, timing):
  a = analyze(items, audio); if none: return items
  keepLast = (timing == runGrouped)
  for each item w:
    first = a.frameAt(w.start)
    last  = min(a.frames - 1, max(0, ceil(w.end / a.frameLength) - 1))
    if first > last: unchanged
    runs    = audibleRuns(a, first, last)
    islands = merge consecutive runs while (next.first - current.last - 1) < TIGHTEN_SPLIT_FRAMES
    if islands empty: unchanged
    (fa, fb) = keepLast ? islands.last : islands.first
    start = w.start; end = w.end
    if fa - first >= TIGHTEN_MIN_SILENT_FRAMES: start = max(w.start, fa · a.frameLength)
    if last - fb  >= TIGHTEN_MIN_SILENT_FRAMES: end   = min(w.end, (fb + 1) · a.frameLength)
    if end - start < MIN_WORD:
      start = max(w.start, end - MIN_WORD)
      end   = min(w.end, start + MIN_WORD)
    w.start = start; w.end = end

audibleRuns(a, from, to):              // a run spans at most BRIDGE_FRAMES consecutive quiet frames
  runs = []; f = from
  while f <= to:
    if !a.audible(f): f += 1; continue
    last = f; quiet = 0
    for g in f+1 ... to: if a.audible(g): last = g; quiet = 0 else: quiet += 1; if quiet > BRIDGE_FRAMES: break
    runs.append((f, last)); f = last + 1
  return runs
```

Apple ranges absorb the silence before a word, so the last island is the word; whisper ranges absorb the silence after it, so the first island is. Fixtures: `shared/fixtures/editing/tighten/*` and `pipeline/*`.

### 7.4 Refine word boundaries

Run `refineWordBoundaries` unchanged on the output of every engine. It is a port of `vox-web/src/utils/wordBoundaries.ts:19-94`, vendored in `tools/fixtures/editing/reference/wordBoundaries.ts`. It widens each word outward to where the sound starts and stops, and each side claims at most half the gap to its neighbour. Where two words touch, it moves the shared edge to the quietest frame within 70 ms.

Constants: lead 0.35 s, tail 0.3 s, bridge 2 frames, touching 0.03 s, valley reach 0.07 s, minimum word 0.04 s.

### 7.5 Unlabeled speech: the filler-in-gap detector (only when `verbatim == false`)

Engines that drop fillers leave an audible gap where "um" was spoken. In the measured TalTech zipformer test, "So, um, today" came back as `So` 0.40–0.64 and `today` 1.36–1.80, with the "um" missing from 0.64–1.36. The detector fills such gaps with an item the user can cut:

```
reached = 0
for k in 0 ... items.count:                         // items sorted by start; k == count is the tail gap
    gapStart = reached
    gapEnd   = k < count ? items[k].start : audio.length / audio.rate
    if k < count: reached = max(reached, items[k].end)
    if !(gapEnd - gapStart >= 0.25): continue
    f0 = max(0, ceil(gapStart / frameLength)); f1 = min(frames - 1, floor(gapEnd / frameLength) - 1)
    f = f0
    while f <= f1:
        if !audible(f): f += 1; continue
        last = f; quiet = 0
        for g in f+1 ... f1: if audible(g) { last = g; quiet = 0 } else { quiet += 1; if quiet > 2 break }
        peak = max(level[f ... last])
        if last - f + 1 >= 10 && peak >= speechLevel * 0.25:
            emit { text: "…", kind: unlabeledSpeech, start: f * frameLength, end: (last + 1) * frameLength,
                   conf: nil, speaker: nil, rawStart: nil, rawEnd: nil, timing: detected }
        f = last + 1
```

The leading gap (before the first word) and the trailing gap (after the last word) are searched too. The found items are merged into the list with a stable sort by start.

The detector cannot tell an "um" from a cough or an untranscribed word. That is why the chip reads "…" and not "um", and why it runs only for non-verbatim engines. The fixture `gaps/breath-and-blip-ignored` pins the breath and blip cases. Change the constants in `editing.md` first, and only on evidence from real recordings (16.4).

### 7.6 Ids and pauses

Set `id = "w" + (index + 1)` in final order. `editing.md` §5.7 derives pauses from consecutive items of any kind: a gap of at least `pauseThresholdSeconds` is a pause.

### 7.7 Fillers and Estonian (non-normative input for `editing.md` §12)

"Cut fillers" counts every `unlabeledSpeech` item, plus `word` items whose current text matches `editing.md` §4.11: `^(um+|uh+|erm+|hmm+)[,.!?]?$` with ASCII case folding. That is VoxConvo parity, it is English-only, and it is not editable in 0.1.0 (design §4.2).

Verbatim engines write Estonian hesitations as words, and the rule never matches them. This applies to ElevenLabs, and to TalTech once 9.9 flips. So for Estonian takes on verbatim engines, "Cut fillers" finds nothing in 0.1.0.

Candidate lists recorded as input for the deferred per-language rule in `editing.md` §12 (not defaults, not implemented in M1):

- en: `um, umm, uh, uhm, erm, er, ah, hmm, mm`
- et: `ee, eee, öö, ööö, ää, äää, mm, hmm`

Discourse fillers (`like`, `you know`, `nagu`, `noh`, `tead`, `tähendab`, `ütleme`, `vot`) are real words in context, so they may only ever be offered as suggestions. The editing spec owns the filler rule.

### 8.2 Response and mapping

A 200 response is a `SpeechToTextChunkResponseModel`:

```json
{
  "language_code": "et",
  "language_probability": 0.98,
  "text": "Tere, ee, täna räägin ...",
  "words": [
    { "text": "Tere,", "type": "word", "logprob": -0.02, "start": 0.12, "end": 0.48, "speaker_id": "speaker_0" },
    { "text": " ", "type": "spacing", "logprob": 0.0, "start": 0.48, "end": 0.61, "speaker_id": "speaker_0" },
    { "text": "(laughs)", "type": "audio_event", "logprob": 0.0, "start": 3.2, "end": 3.9, "speaker_id": "speaker_0" }
  ],
  "audio_duration_secs": 61.3,
  "transcription_id": "…"
}
```

Each `words[]` item has `text`, `type`, `logprob` (≤ 0), `start` and `end` (nullable), and optional `speaker_id`, `characters` and `channel_index`. Map them in order to `RawToken`s, all with `group = 0` and `joinsPrevious = false`:

| `type` | RawToken |
|---|---|
| `word` | `text` trimmed; `start` and `end` as given; `conf = exp(logprob)` clamped to [0, 1]; `speaker = diarize ? speaker_id : nil` |
| `audio_event` | the same, with `kind = .event` and `conf = nil` |
| `spacing` | skipped |
| anything else | skipped; log the type name once per response, never the text |

Then:

- `language`: normalise `language_code` with `languageCodes.iso639_3` from the catalogue (the docs show both `eng` and `en`). Two-letter codes are kept as they are.
- `languageProbability = language_probability`, `providerRequestID = transcription_id`.
- `timing = .native`, `verbatim = true`, `grouping = (.lastToken, .single, false)`.
- `engine = EngineRef(id: .elevenlabs, modelId: "scribe_v2", modelSha256: nil, engineVersion: "scribe_v2", locale: nil)`.

Unknown response fields are ignored. A 200 whose body is not a chunk response, for example one with `transcripts[]`, is a `providerError` ("unexpected response shape").

Always map `logprob` to `conf` as above, never a constant. Never log transcript text or any part of a key.

### 8.3 Transport, retries, timeouts

- Upload from a file-backed body:
  - macOS: `URLSession.upload(for:fromFile:)` with a delegate reporting bytes sent. The multipart body is written to a temp file next to the WAV first.
  - Windows: `HttpClient` with `MultipartFormDataContent` and a `StreamContent` over a `FileStream` wrapped in a progress-counting stream.
- Timeouts: connect 30 s; idle 300 s with no bytes in either direction; whole request 2 h. One hour of audio is about 115 MB.
- Retries follow `doc/architecture.md` §10.1 rule 5:
  - Up to 3 attempts on 429, 5xx and 529, with 1 s then 2 s backoff. Honour `Retry-After` up to 30 s.
  - Never retry 400, 401, 403 or 422.
  - A transport failure during the upload counts as one attempt.
- Mapping: 401 → `keyRejected`. 403, or a 401 whose JSON body mentions a permission → `keyPermissionMissing`. 422 → `providerError` with `detail[0].msg`. A body that mentions quota or credits → `quotaExceeded`. Bodies are truncated to 200 characters after redaction.
- Cancelling invalidates the task, and the transcript column says "Cancelled. ElevenLabs may still bill audio it already received."

### 8.4 Limits

Check these before uploading. The values are in the catalogue under `engines[elevenlabs].limits`.

| Limit | Value | Code |
|---|---|---|
| Minimum duration | 0.1 s | `noSpeech` |
| Maximum duration | 36 000 s (10 h) | `mediaTooLong` |
| Maximum upload | 3 000 000 000 bytes | `mediaTooLong` |

The API reference says files must be under 5.0 GB; the capability page says 3 GB. The stricter value applies. Ten hours of 16 kHz 16-bit mono is 1.152 GB, so the duration limit always binds first.

ElevenLabs transcribes files longer than 8 minutes in parallel internally, with concurrency `min(4, ceil(duration / 480))`. VoxClip sends one request per take and does not chunk.

### 9.3 Decode units (VAD chunking)

VoxClip runs Silero VAD itself and decodes each speech region with its own `whisper_full` call. It does **not** set `whisper_full_params.vad`. With the built-in VAD, `t_dtw` stays in VAD-processed time and only `t0`/`t1` are mapped back; see the `whisper_full_get_token_t0` comment in `whisper.h` 1.9.5. Slicing the audio ourselves keeps every timestamp on one timeline.

```
samples = Float32(audio-16k.wav) / 32768
// 1. Level normalisation: a copy used only for VAD and decoding, never written back to media
active  = 10 ms frames whose RMS > -60 dBFS
gainDb  = active.isEmpty ? 0 : clamp(-20 - rmsDb(samples in active frames), -20, +30)
norm    = clamp(samples * 10^(gainDb / 20), -1, 1)
// 2. VAD
regions = SileroVAD(norm, threshold 0.30, min_speech_duration_ms 250, min_silence_duration_ms 2000,
                    max_speech_duration_s FLT_MAX, speech_pad_ms 400, samples_overlap 0.10)
units   = regions clamped to [0, duration], overlapping or touching regions merged
if units.isEmpty: throw noSpeech
// 3. Decode
for (u, unit) in units:
    whisper_full(ctx, params, norm[unit.startSample ..< unit.endSample])
    → tokens: times + unit.start; group = a running (unit, segment) counter
```

The VAD settings come from the TalTech/Aivo long-audio recipe (`-vt 0.3 -vsd 2000 -vp 400`, RMS to −20 dBFS, gain capped at +30 dB). In that evaluation, the model without VAD hallucinated on silence and music, up to 80 false words per minute. Without level normalisation, the VAD dropped quiet speech.

On macOS:

1. Create the context with `whisper_vad_default_context_params()` and `whisper_vad_init_from_file_with_params(path, cparams)`.
2. Run `whisper_vad_segments_from_samples(vctx, vparams, ptr, n)`.
3. Read `whisper_vad_segments_n_segments` and `whisper_vad_segments_get_segment_t0/_t1`. They return centiseconds as `float`, so divide by 100.
4. Free with `whisper_vad_free_segments` and `whisper_vad_free`.

On Windows: `WhisperVadFactory.FromPath(vadPath).CreateBuilder().WithThreshold(0.30f).WithMinSpeechDuration(TimeSpan.FromMilliseconds(250)).WithMinSilenceDuration(TimeSpan.FromMilliseconds(2000)).WithSpeechPadding(TimeSpan.FromMilliseconds(400)).WithSamplesOverlap(TimeSpan.FromMilliseconds(100)).Build().DetectSpeech(samples)`. It returns `VadSegmentData { Start, End }` as `TimeSpan`.

### 9.5 Tokens to RawToken

All whisper times are in **centiseconds**.

**macOS** (C API, byte-exact):

```
eot = whisper_token_eot(ctx)
for s in 0 ..< whisper_full_n_segments(ctx):
    g = nextGroup(); pending = []; pendingStart = nil; first = true
    for k in 0 ..< whisper_full_n_tokens(ctx, s):
        if whisper_full_get_token_id(ctx, s, k) >= eot: continue          // SOT, language, timestamps, EOT, [_BEG_]
        d  = whisper_full_get_token_data(ctx, s, k)
        t0 = (dtw && d.t_dtw >= 0 ? d.t_dtw : d.t0) / 100.0 + unit.start
        bytes = pending + bytesOf(whisper_full_get_token_text(ctx, s, k))
        if !endsWithCompleteUTF8(bytes): pending = bytes; pendingStart = pendingStart ?? t0; continue
        text = String(decoding: bytes, as: UTF8.self); start = pendingStart ?? t0; pending = []; pendingStart = nil
        startsWord = first || text.hasPrefix(" ")
        emit RawToken(text: text without leading spaces, joinsPrevious: !startsWord,
                      start: clamp(start, unit.start, unit.end),
                      end:   clamp(d.t1 / 100.0 + unit.start, unit.start, unit.end),
                      conf:  Double(d.p), group: g)
        first = false
```

`endsWithCompleteUTF8` checks that the trailing continuation bytes complete the sequence started by the last lead byte. A byte-level BPE token can end in the middle of a multi-byte character, such as an Estonian `õ` or an emoji.

**Windows** (Whisper.net). `SegmentData.Tokens[]` gives `Id`, `Text`, `Start`, `End` and `DtwTimestamp` in centiseconds, plus `Probability`. Whisper.net decodes each token's text on its own, so a character split across two tokens arrives as U+FFFD.

1. Skip tokens with `Id >= eot`, where `eot = multilingual ? 50257 : 50256` (catalogue `whisper.multilingual`). As a safety net, also skip tokens whose `Text` matches `\A\[_.*\]\z` or `\A<\|.*\|>\z`.
2. Emit RawTokens exactly as on macOS. Use `DtwTimestamp` when DTW is on and the value is `>= 0`, otherwise `Start`.
3. If any kept token of a segment contains U+FFFD, repair the segment:
   - Group its tokens into words with the leading-space rule, and split `SegmentData.Text.Trim()` on whitespace.
   - If the counts are equal, the first token of word *i* takes the text of segment word *i*. The other tokens of that word become empty with `joinsPrevious = true`.
   - Otherwise remove the U+FFFD characters and log a warning.

In both cases: `grouping = (.nextWordStart, .mean, true)`, `timing = dtw ? .dtw : .tokenGrouped`, `verbatim` from the catalogue model, `language` = the forced code, and `engine = EngineRef(id: .whispercpp, modelId: <catalogue id>, modelSha256: <catalogue file sha256>, engineVersion: …, locale: nil)`.

### 9.6 Keeping fillers: the initial prompt

Whisper usually drops "um" and "uh" unless the prompt shows them. The OpenAI prompting guide gives this prompt for keeping them: `Umm, let me think like, hmm... Okay, here's what I'm, like, thinking.`

| Model | Prompt |
|---|---|
| OpenAI models, English | the prompt above, set by the catalogue through `initialPromptByLanguage` |
| TalTech | none. The models were fine-tuned on verbatim transcripts, and a foreign-style prompt can hurt a fine-tune |
| Any model, other languages | none, until a native-speaker prompt has been tested |

Whatever the prompt does, the unlabeled-speech detector (7.5) still runs, because every whisper model is `verbatim: false` in the v1 catalogue.

### 9.7 DTW alignment heads

- `LARGE_V3_TURBO` is the correct preset for OpenAI large-v3-turbo.
- The TalTech fine-tune's `generation_config.json` at revision `310c5509` lists `alignment_heads [[2,4],[2,11],[3,3],[3,6],[3,11],[3,14]]`. That is identical to `openai/whisper-large-v3-turbo`: the heads were inherited, not re-estimated, and fine-tuning can move attention.
- Section 16.4 measures word-start error with DTW on and off. If DTW is worse on Estonian, add `"dtwDefault": false` to the TalTech catalogue entries. Timing then becomes `tokenGrouped`; tighten and refine still apply.

### 9.8 Language detection

Routing uses this only when the language is `auto` and the engine mode is on-device (11.2).

- Use the first 30 s of the first unit of `norm`.
- macOS: `whisper_pcm_to_mel`, then `whisper_lang_auto_detect(ctx, 0, threads, probs)`. Windows: `processor.DetectLanguageWithProbability(samples)`.
- Use an installed OpenAI multilingual model (`whisper-large-v3-turbo-*`), never a TalTech model.
- Accept the top language when its probability is at least 0.5. Otherwise ask the user.

### 9.9 Verbatim status of whisper models

Every whisper model in the v1 catalogue has `verbatim: false`, so the detector (7.5) covers dropped fillers. That includes TalTech.

`editing.md` and the project schema description name the TalTech model as an example of a verbatim engine. It was fine-tuned on verbatim transcripts, but filler recall has not been measured.

Flip TalTech to `verbatim: true` once 16.4 shows a filler recall of at least 0.9 on the bilingual test set. If the model drops fillers, the cost of a wrong `true` is that "Cut fillers" silently misses them. The cost of a wrong `false` is a few extra "…" chips. That is why `false` is the default.

## 10. Apple SpeechTranscriber (`apple-speech`, macOS 26+)

### 10.1 API surface used

Everything below is available from macOS 26, the deployment target. Names come from the Speech framework interface in the macOS 27 SDK.

- `SpeechTranscriber.isAvailable`, `supportedLocales`, `installedLocales`, `supportedLocale(equivalentTo:)`.
- `SpeechTranscriber(locale:transcriptionOptions:reportingOptions:attributeOptions:)`. `ResultAttributeOption` has `.audioTimeRange` and `.transcriptionConfidence`.
- `AssetInventory`:
  - `status(forModules:)` returns `.unsupported`, `.supported`, `.downloading` or `.installed`;
  - `assetInstallationRequest(supporting:)` returns an `AssetInstallationRequest?` with `progress` and `downloadAndInstall()`;
  - `reserve(locale:)`, `release(reservedLocale:)`, `reservedLocales`;
  - `maximumReservedLocales` (5 measured).
- `SpeechAnalyzer(modules:)`, `prepareToAnalyze(in:)`, `analyzeSequence(from: AVAudioFile)`, `finalizeAndFinish(through:)`, `cancelAndFinishNow()`, `bestAvailableAudioFormat(compatibleWith:considering:)`.
- `SpeechTranscriber.Result { range: CMTimeRange; resultsFinalizationTime: CMTime; text: AttributedString }`. Each run of `text` carries `audioTimeRange: CMTimeRange` and `transcriptionConfidence: Double`.
- `SFSpeechError.Code`: `noModel`, `assetLocaleNotAllocated`, `tooManyAssetLocalesAllocated`, `cannotAllocateUnsupportedLocale`, `insufficientResources`, `unexpectedAudioFormat`, `incompatibleAudioFormats`, `audioDisordered`, `moduleOutputFailed`.

`AssetInputSequenceProvider` reads an `AVAsset` directly but needs macOS 27. v1 uses the file path in 10.4 on every OS version, so macOS 26 and 27 behave the same.

### 10.2 Locales

- The engine is offered only when `SpeechTranscriber.isAvailable` is true and `supportedLocale(equivalentTo:)` returns a locale for the language. Neither `SpeechTranscriber` nor `DictationTranscriber` supports Estonian (measured).
- For a bare language code `L`, pick the locale in this order:
  1. the first entry of `Locale.preferredLanguages` whose language is `L` and that `supportedLocale(equivalentTo:)` accepts;
  2. otherwise `supportedLocale(equivalentTo: Locale(identifier: L))`;
  3. otherwise the language is unsupported.
- The chosen locale's `identifier(.bcp47)` (hyphenated, for example `en-GB`) becomes `transcript.language` and `EngineRef.locale`. Never store `Locale.identifier`, which can be `en_GB` and fails the schema pattern.
- There is no auto-detection. With `LanguageChoice.auto` the engine is not offered.
- The catalogue's `localesSnapshot` is documentation only. The runtime lists are authoritative.

### 10.3 Asset flow

```
let t = SpeechTranscriber(locale: loc, transcriptionOptions: [], reportingOptions: [],
                          attributeOptions: [.audioTimeRange, .transcriptionConfidence])
switch await AssetInventory.status(forModules: [t]) {
case .installed: break
case .unsupported: throw transcriptionLanguageUnsupported
case .supported, .downloading:
    if !(await AssetInventory.reservedLocales).contains(loc) {
        if (await AssetInventory.reservedLocales).count >= AssetInventory.maximumReservedLocales {
            release the least recently used locale in VoxClip's ledger that no running job uses
        }
        try await AssetInventory.reserve(locale: loc)
    }
    if let req = try await AssetInventory.assetInstallationRequest(supporting: [t]) {
        forward req.progress.fractionCompleted to prepare(progress:)
        try await req.downloadAndInstall()
    }
}
```

- The ledger is `<data>/apple-speech-locales.json`, a list of `[{locale, lastUsed}]`. Every transcription updates `lastUsed`.
- `transcriptionOptions` is empty, because `.etiquetteReplacements` would mask words. `reportingOptions` is empty, so only final results arrive (no volatile ones).
- Error handling:

  | Error | Action |
  |---|---|
  | `assetLocaleNotAllocated` | reserve, then retry once |
  | `tooManyAssetLocalesAllocated` | release the least recently used locale, then retry once |
  | `insufficientResources` | `diskFull` |
  | `noModel`, `cannotAllocateUnsupportedLocale` | `transcriptionLanguageUnsupported` |
  | anything else | `speechAssetsUnavailable` |

- While downloading, the UI shows "Downloading Apple's {Language} speech model…" with the fraction. macOS hosts the files, and VoxClip shows no size it does not know.
- Settings → Transcription lists the selected language's Apple speech model, with Download, progress and Cancel, Retry after failure, or Installed. Auto asks the user to choose a language. A missing-assets message in the transcription sheet opens that pane through Models and keys…. Downloads are app-owned and continue after Settings closes; cancellation is silent. A language chosen during a download is checked after that download finishes.

### 10.4 Analysis

```
let fmt = await SpeechAnalyzer.bestAvailableAudioFormat(compatibleWith: [t], considering: float32Mono16k)
convert audio-16k.wav to fmt with AVAudioConverter → <data>/Cache/<contentKey>/apple-<sampleRate>-<channels>.caf (LPCM)
let file = try AVAudioFile(forReading: cafURL)
let analyzer = SpeechAnalyzer(modules: [t])
try await analyzer.prepareToAnalyze(in: file.processingFormat)
let collector = Task { var out: [SpeechTranscriber.Result] = []; for try await r in t.results { out.append(r) }; return out }
if let last = try await analyzer.analyzeSequence(from: file) { try await analyzer.finalizeAndFinish(through: last) }
else { await analyzer.cancelAndFinishNow() }
let results = try await collector.value
// On Task cancellation: await analyzer.cancelAndFinishNow(), then throw cancelled.
```

Progress is `max(result.range.end.seconds) / durationSeconds`.

### 10.5 Runs to RawToken

Each result `r` starts a new `group`. For each run of `r.text.runs`:

```
s = String(r.text[run.range].characters)
if s is whitespace only: boundaryPending = true; continue
cjk = the language is zh, ja or yue
startsWord = firstRunOfResult || boundaryPending || s.first!.isWhitespace || (cjk && !isPunctuationOnly(s))
emit RawToken(text: s.trimmed, joinsPrevious: !startsWord,
              start: run.audioTimeRange?.start.seconds, end: run.audioTimeRange?.end.seconds,
              conf: run.transcriptionConfidence, group: g)
boundaryPending = false
```

Then `grouping = (.lastToken, .min, false)`, `timing = .runGrouped`, `verbatim = false`, and `engine = EngineRef(id: .appleSpeech, modelId: nil, modelSha256: nil, engineVersion: "macOS <version> Speech", locale: loc.identifier(.bcp47))`.

### 10.6 Permission

Info.plist carries `NSSpeechRecognitionUsageDescription`; the string is defined once in `doc/release.md` §2.2: "VoxClip transcribes your videos on this Mac with Apple's on-device speech recognition. Audio stays on this Mac."

VoxClip does not call `SFSpeechRecognizer.requestAuthorization` up front. If analysis fails with an authorization error, it calls it once and retries. Whether on-device `SpeechAnalyzer` prompts at all is still open (section 17).

## 11. Language routing

### 11.1 Inputs

- **Engine mode** (Settings → Transcription → Engine, `doc/design.md`):
  - `local`, labelled "On this {Mac/PC}": the default;
  - `apple`, labelled "Apple on-device": macOS only;

### 11.2 Algorithm

```
route(L, mode):
    if mode == elevenlabs:   return keyPresent ? Plan(elevenlabs, L) : Prompt.addKey(alsoOffer: route(L, local))
    if mode == ask:          return Prompt.choose([route(L, local) with its size, elevenlabs with its cost if keyPresent])
    if mode == apple:        return appleSupports(L) ? Plan(apple-speech, locale(L))
                                                     : Prompt.explain("Apple can't transcribe {language}.", alsoOffer: route(L, local))
    // mode == local
    if L == auto:
        if an OpenAI multilingual model is installed:
            (lang, p) = whisperDetect()                                    // 9.8
            if p >= 0.5: return route(lang, local)
        return Prompt.chooseLanguage(default: the UI language)             // never upload to find out
    d = catalogue.defaults.byLanguage[L] ?? catalogue.defaults.byLanguage["*"]
    if an installed model m in d[platform].local has languages == [L]:     return Plan(whispercpp, m)   // language-specific model the user chose
    if platform == macos && appleSupports(L):                               return Plan(apple-speech, locale(L))
    if an installed model m in d[platform].local supports L:               return Plan(whispercpp, m)
    rec = ram < defaults.lowMemoryThresholdBytes ? (d.lowMemoryDownload ?? d.recommendedDownload) : d.recommendedDownload
    return Prompt.download(rec, alsoOffer: keyPresent ? elevenlabs : nil)
```

The resulting defaults:

| Language | macOS, `local` | Windows, `local` | Cloud |
|---|---|---|---|
| `et` | TalTech verbatim Q8_0 (874 MB). Apple is never used for Estonian. | TalTech verbatim Q8_0 (874 MB); Q4_0 (474 MB) on machines with less than 8 GB RAM | ElevenLabs Scribe v2 (Estonian in the "Excellent", ≤ 5% WER, tier) |
| `en` | Apple Speech (no in-app download), unless small.en is installed | Whisper large-v3-turbo Q5_0 (574 MB); small.en Q5_1 (190 MB) on machines with less than 8 GB RAM | ElevenLabs |

### 12.2 Storage

| Item | Location (`<data>` from `doc/architecture.md` §2.5; `VOXCLIP_DATA_DIR` overrides it) |
|---|---|
| Model files | `<data>/Models/whispercpp/<modelId>/<file name>` |
| Installed marker | `<data>/Models/whispercpp/<modelId>/installed.json`: the catalogue entry plus `installedAt`, written last and atomically |
| Partial download | `<file name>.partial`, plus `<file name>.partial.json` holding `{url, bytes, sha256}` |

A model counts as installed when all of these hold:

- `installed.json` exists;
- its `files` match the current catalogue entry by name, bytes and sha256;
- every file exists at the expected size.

A catalogue update that changes a hash marks the old install "Update available". Sha256 is checked at install time, not at every launch; at launch a size mismatch is enough to mark a model broken. Models are not cache entries: only the user removes them.

### 12.3 Download algorithm

1. **Queue.** `download(modelId)` does nothing if the model is installed or already queued. It queues the `requires` models first. One model download runs at a time.
2. **Free space.** The volume needs `remaining bytes × 1.1 + 1 GiB` free. Check with `volumeAvailableCapacityForImportantUsageKey` on macOS and `DriveInfo.AvailableFreeSpace` on Windows. If there is not enough, fail with `diskFull`. macOS model-store unit tests inject capacity independently of the host's free space; production initializers keep the real volume lookup.
3. **Confirm.** Before the first byte of each model, show a confirmation, once per model: a sheet on the window on macOS, a `ContentDialog` on Windows.
   - Title: "Download {displayName} from huggingface.co?"
   - Body: "This model is published by {publisher}, not by VoxClip. It downloads from Hugging Face ({size}) and runs on this {Mac/PC}. License: {license}. By downloading you accept the publisher's terms." Then a blank line and `{attribution}`.
   - Buttons: [Download] (default), [Cancel], [Open source page] (opens `sourcePage`).
   - Required files such as Silero VAD are counted in the same sheet and size. They are never confirmed separately.
4. **Fetch each file.**
   - If the final file already exists with the right size and sha256, skip it.
   - If a `.partial` exists for the same URL and sha256, resume it with `Range: bytes=<partialSize>-`. A 206 appends; a 200 truncates the partial and restarts.
   - Stream to disk:
     - macOS: a `URLSession` task with a delegate that writes chunks to the partial;
     - Windows: `HttpClient.GetAsync(HttpCompletionOption.ResponseHeadersRead)`, copying in 1 MiB chunks.
   - Follow the 302 to the CDN host. Never read the body byte by byte; that once tripped Superscribe's idle timeout on large files.
   - Timeouts: 300 s idle, 3 h per file.
   - Retries per `doc/architecture.md` §10.1 rule 5. A retry resumes from the partial.
   - Errors, identical on both platforms:
     - HTTP 429 after retries: `rateLimited`, "Hugging Face is busy. Try again in a minute."
     - other non-2xx: `providerError`, "Hugging Face answered {status}: The model download could not be completed." The response body is never shown.
     - transport failure after retries: `offline`.
   - Progress: "Downloading {model} · 37% · {done} of {total}" [Cancel] (`doc/design.md`). The total includes the `requires` files.
5. **Verify.** Hash with SHA-256 incrementally while writing; on resume, hash the existing partial first.
   - Mismatch: delete the partial and fail with `modelChecksumMismatch`.
   - Match: atomically rename the partial over the final name.
6. **Mark installed.** Write `installed.json`.
7. **Cancel and remove.** Cancel stops the request and keeps the partial for a later resume. Remove deletes the whole model folder.

### 12.4 Licences and attribution

About lists every installed model as "{displayName} · {license}", followed by its `attribution` and `citation` as selectable text. The TalTech models must show the citation. All v1 models are MIT. A model with a non-commercial or unstated licence must not be added to the catalogue.

## 13. Progress, cancellation, concurrency

### 13.1 Progress

One progress value covers the import, built from stages. The copy comes from `doc/design.md` §13.

| Stage | Range | Label | Source |
|---|---|---|---|
| Read and extract audio | 0.00–0.10 | "Reading video…", then "Extracting audio…" | last PTS / duration |
| Prepare (model or Apple assets) | own bar | "Downloading {model} · 37% · {done} of {total}" / "Downloading Apple's {Language} speech model…" | bytes, or `AssetInstallationRequest.progress` |
| Transcribe, ElevenLabs | 0.10–0.50 upload, then 0.50–0.95 indeterminate | "Transcribing with ElevenLabs · 42%" during upload, then "Transcribing with ElevenLabs…" with the elapsed time | bytes sent / file size |
| Transcribe, whisper | 0.10–0.95 | "Transcribing on this {Mac/PC} · 42%" | (Σ finished unit seconds + current unit seconds × callback %) / Σ unit seconds |
| Transcribe, Apple | 0.10–0.95 | "Transcribing on this Mac · 42%" | latest result end / duration |
| Align words | 0.95–1.00 | "Aligning words…" | sections 6 and 7 |

Screen readers hear an announcement every 10%. Under Reduce Motion, indeterminate progress shows a static label.

### 13.2 Cancellation

- Every stage can be cancelled from the import sheet and the transcript column.
- Local engines must stop within 1 s:
  - whisper: through `abort_callback` on macOS and the `CancellationToken` on Windows;
  - Apple Speech: through `cancelAndFinishNow()`.
- Partial results are discarded. The project returns to "Not transcribed" (`transcript: null`) and the video stays playable. The extracted audio stays in the cache for the retry.
- Cancellation shows no error message and is logged at `info`.

### 13.3 Logging

Logs record the engine, model id, durations, HTTP status, byte counts and `transcription_id`. They never record keys, transcript text, prompts or request and response bodies (`doc/architecture.md` §11). The redactor handles the `xi-api-key` header and `sk_…` key shapes.

### 13.4 Concurrency

- A project runs at most one transcription job at a time.
- Local jobs (whisper and Apple) run one at a time across the app, because they share the GPU and memory. Other local jobs wait and show "Waiting for the current transcription…".
- At most two ElevenLabs jobs run at once across the app, alongside any local job.
- Jobs for the same source with the same settings and data folder share one raw result entry (14.2) and run one at a time. A job starts at once when its kind has room and no identical job is running. Otherwise it waits without holding a place, so it never holds back a job of the other kind or a job for another source, other settings or another data folder. When a job finishes, its place goes to the oldest waiting job of its kind whose identical job is not running, and no job that asked after that one can take the place first.

## 14. Caching

### 14.1 What is cached

Under `<data>/Cache/<contentKey>/` (`doc/architecture.md` §8). `contentKey` is the source content key from §8.1.

| File | Content |
|---|---|
| `audio-16k.wav` | the extracted transcription audio (section 4) |
| `apple-<rate>-<channels>.caf` | Apple's input copy (10.4) |
| `transcripts/<engine>-<model or "none">-<language or "auto">-<opts8>.json` | the raw result (14.2) |
| `transcripts/<raw file>.unreadable-<unix ms>` | a file that stood at a raw-result path but did not read as that request's entry, set aside before a paid upload (14.3); kept for manual recovery and never read back |

The normalised `Transcript` lives only in the project file. It is not cached.

### 14.2 Raw result entry

```json
{
  "schema": "voxclip-raw-transcript/1",
  "key": { "engine": "whispercpp", "model": "taltech-et-verbatim-2604-q8_0",
           "modelSha256": "0e6308a9…", "adapterVersion": 1, "language": "et", "locale": null,
           "diarize": false, "numSpeakers": null, "keyterms": [], "dtw": true, "audioTrackIndex": 0 },
  "createdAt": "2026-10-25T12:00:00.000Z",
  "raw": { /* RawTranscript (3.2) */ },
  "providerResponse": null
}
```

- **Canonical JSON of `key`:** UTF-8, object keys sorted by Unicode code point, no whitespace, `keyterms` sorted (ordinal), numbers in shortest round-trip form, `null` written.
- **`rawKey`** = lowercase hex SHA-256 of that canonical JSON. It is stored in `transcript.rawKey`, so a project can find its raw result again.
- **`opts8`** = the first 8 characters of `rawKey`.
- `providerResponse` holds the unmodified ElevenLabs JSON, so a later adapter version can re-map it without paying again. It is `null` for local engines.
- On macOS, the transcription service preserves an entry already written by an engine for the same key, including when a wrapper forwards to ElevenLabs. Generic cache writes must not discard the paid response or its exact bytes.
- A lookup must match the whole `key`, not only the file name.
- The OS version and engine patch versions are not part of the key. A raw result stays valid across them. The post-process (section 7) runs again whenever a raw result, fresh or from a cache hit, is turned into a new `Transcript` (a new import of the same file, or Transcribe Again). Opening a project never reruns it: stored word timings are never recomputed (`editing.md` §5).

### 14.3 Policy

- Writes are atomic: a temp file, then a rename.
- Eviction follows `doc/architecture.md` §8.2: least recently used, with a 5 GB default cap, and never for entries an open project uses. Because the project file holds the transcript, eviction never loses work. It can only cost a repeat transcription of a re-imported file. Raw ElevenLabs results should be the last files evicted inside an entry, since they are small and were paid for.
- Before an ElevenLabs upload, look up the entry. On a hit, skip the upload and show "Using the earlier ElevenLabs transcript of this file (no charge)." The same reuse applies to local engines.
- A paid response is never overwritten. Before an ElevenLabs upload, a file at the entry path that is not this request's readable entry (it does not decode, or it has another key or schema; on macOS, anything but this key's own placeholder) is renamed to `<name>.unreadable-<unix ms>`, never replacing an existing file. If the rename fails, transcription stops with the cache-unavailable error. Set-aside files are never read back; eviction keeps them with `transcripts/` in its first pass and removes them only with the whole entry (`doc/architecture.md` §8.2).

### 14.4 Re-transcription

"Transcribe again…" lets the user choose a different engine, model or language. It builds a new `Transcript` with new ids. `editing.md` §10.5 then requires clearing the cuts, corrections, clips and AI results, after a confirmation that names what will be lost.

## 15. CLI (`voxclip-cli`, both platforms)

The CLI follows `doc/architecture.md` §9:

```
voxclip-cli transcribe --open <media> --engine whisper|apple|elevenlabs [--model <catalogue id>]
                       [--language auto|<bcp47>] --out <project.voxclip> [--json]
```

- The aliases `whisper` and `apple` map to `whispercpp` and `apple-speech`. `apple` is macOS only.
- The ElevenLabs key comes only from the `VOXCLIP_ELEVENLABS_API_KEY` env var (architecture §9.4). The CLI never reads the Keychain or DPAPI.
- Exit codes: 4 transcription failed; 7 key or model missing; 3 input unsupported; 6 cancelled.

Additions in the architecture's CLI table (§9.2), used by section 16:

- `--raw-out <file>` writes the cache entry (14.2).
- `--no-dtw` and `--diarize` set the matching options.
- `voxclip-cli models list|install <id>|verify <id>|remove <id>` manages models headlessly, under `VOXCLIP_DATA_DIR`.

## 16. Acceptance tests

### 16.1 Shared fixtures (CI, both platforms)

Fixtures live in `shared/fixtures/transcription/` (hand-written to this section; their README says so; created by the shared-fixtures work in `doc/plan.md`). There are two shapes:

- word assembly: `{name, rule, timelineStart, tokens: [RawToken], expect: [RawWord]}`;
- pipeline: `{…, audio: <"vox-take-v1" generator input as in editing.md §11.4>, timing, verbatim, expectWords: [TimedWord]}`.

Swift (`swift test`) and C# (`VoxClip.Core.Tests`, also run on the macOS runner) must produce byte-identical JSON. Required cases:

1. ElevenLabs: `spacing` skipped; `audio_event` becomes `event`; `logprob` becomes `conf`; with diarize off, `speaker` is nil.
2. ElevenLabs word with `start: null`: `cleanWords` drops it.
3. Punctuation: tokens `"Tere"`, `","` become `"Tere,"` without extending its end; a `"("` prefix attaches to the next word.
4. Whisper `.nextWordStart`: a word ends at the next word's start within its group. The last word of a group ends at its last token's end, and is at least 0.04 s long.
5. Whisper UTF-8 split: two tokens whose bytes together form `õ` give the single word `"õhtu"`. The Windows U+FFFD repair yields the same output from the same segment text.
6. Whisper special tokens are skipped: ids ≥ eot, and `[_BEG_]`.
7. Bracket events: `"[laughs]"` becomes an event; `"(soft"` and `"music)"` merge into one event; `"[BLANK_AUDIO]"` is dropped.
8. Apple runs: a whitespace-only run starts a new word; a punctuation run joins the previous word; `conf` is the minimum; each CJK run starts a word.
9. `timelineStart = 0.5` shifts every time by 0.5.
10. Language codes: `est` → `et`, `eng` → `en`, `cmn` → `zh`, `xyz` stays `xyz`.
11. Cache keys: the same key in a different property order gives the same `opts8`.
12. Catalogue integrity (12.1).

The pipeline cases are already covered by `shared/fixtures/editing/pipeline/*`, `tighten/*` and `gaps/*`. The transcription tests must run them too, through `RawWord` input.
