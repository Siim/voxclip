# Background music

Status (2026-11-04): built on Mac (Core, Media, App). Windows Core opens, validates and saves projects with music
unchanged, and refuses to render or export them (§8).

User decisions (2026-11-04): music comes from three sources (an open library, as CapCut offers; Eleven Music; your own
files), and Claude suggests what suits the video. The approved mockup "Fewer moves, music and captions", part C: the
Music section shows Claude's best three across sources, each with ▶, a source badge and Use; below them "Search music or
add a file…"; an M1 Music lane on the timeline; music sits under the voice automatically: it dips while you talk and
fades out at the end. One volume slider.

## 1. Summary

| Source | Where | Licence | Cost | When it is fetched |
|---|---|---|---|---|
| Free library | Openverse audio search | CC0, CC BY, Public Domain Mark only | free | the file downloads when the user (or the one-click plan) presses Use |
| Generated | Eleven Music compose | generated (ElevenLabs terms) | $0.15 per minute, priced on the button | when the user presses "Make · $x" |
| Your music | the Music folder, or Add a file… | own | free | read from disk on Use |

A used track is copied into `<data folder>/Music/<projectId>/music-<slug>-<hash8>.<ext>` and recorded in the project.
The project never stores audio.

## 2. Project contract

`music` is an optional root array of the project document (`shared/schemas/project.schema.json` `$defs.music`,
`$defs.musicAsset`), generated by `tools/schemas/generate_music_schema.py`.

**Schema-version decision: music stays in schemaVersion 4.** Version 4 is unreleased (0.1.0 is Unreleased) and is
already the version that carries optional root features (`contextDemo`, `motionCues`). `music` is omitted when empty, so
a project without music saves byte-identically and keeps its version. Versions 1–3 must not carry it; adding a first
track promotes a project to 4 through the reviewed v3 policy (`ContextDemoProject.upgradeToV4`). A legacy v2 project with
paid segments still needs its explicit Voice Lab review first.

Each entry has every key, `null` where a source has no value:

| Key | Type | Rule |
|---|---|---|
| `id` | identifier | unique |
| `clipId` | identifier or null | the clip it plays under; null is the full-video export. At most one entry per value, and the clip must exist |
| `asset.file` | `<projectId>/music-<slug>.<mp3\|m4a\|wav\|aif\|aiff\|flac>` | the folder must be the project's own id |
| `asset.sha256` | 64 lower-case hex | |
| `asset.durationSeconds` | number, 0 < d ≤ 1,800 | |
| `source` | `library`, `generated`, `file` | |
| `title` | 1–200 characters | |
| `creator` | 1–200 characters or null | |
| `license` | `cc0`, `by`, `pdm`, `generated`, `own` | library: cc0, by or pdm (never nc, nd or sa); generated: generated; file: own |
| `attribution` | 1–1,000 characters or null | required for `by` |
| `sourceUrl` | `https://…` ≤ 2,048, or null | required for library |
| `prompt` | 1–2,000 characters or null | required for generated, null otherwise |
| `gainDb` | −40…0 | the bed level relative to the measured speech loudness; −20 by default |
| `ducking` | boolean | dip about 12 dB under speech; true by default |
| `fadeInSeconds`, `fadeOutSeconds` | 0…10 | 0.5 and 1.5 by default |
| `startOffsetSeconds` | ≥ 0 and < the track's duration | where in the track the clip's music starts |

Both Cores also check the wire shape before decoding: exact keys and JSON types (a number never stands in for a string or
a boolean) and a non-empty list. Removing a clip removes its track; replacing the transcript keeps only the full-video
track; relinking the source keeps music (it does not depend on the source).

Shared vectors: `shared/fixtures/music/music-project.voxclip` and `music-wire-cases.json`
(`voxclip-music-wire-cases/1`, `tools/fixtures/music/generate_music.py`). Swift and C# `MusicProjectWireTests` replay
every case; `tools/schemas/test_music_schema.py` checks the schema half. `check_drift.py` runs both generators.

## 3. Sources

### 3.1 Free library: Openverse

`GET https://api.openverse.org/v1/audio/?q=<words>&license=cc0,by,pdm&category=music&page_size=20`, anonymous, no
credentials or cookies. The lead checked it live on 2026-11-04: the results are mostly Jamendo, CC BY, each with a
ready `attribution` string. VoxClip:

- keeps only `cc0`, `by` and `pdm` results, again on its side, so `by-nc`, `by-sa`, `by-nd` and the rest never show;
- keeps only HTTPS files and landing pages, a known audio type (`mp3`/Jamendo `mp32`, `wav`, `flac`, `m4a`, `aiff`),
  10 s to 30 min, not `mature`, and for CC BY only results that carry an attribution;
- ranks instrumental matches and the brief's words first, tracks long enough not to loop next, and vocals last;
- sends one search per query (cached), and on a 429 sends nothing more until its `Retry-After` passes (otherwise
  15 s, doubling to 10 min). It never retries on its own. Anonymous limits were 20 per minute and 200 per day;
- downloads the file only on Use (at most 60 MB, refused when the host sends text or JSON).

### 3.2 Generated: Eleven Music

Verified against the API reference on 2026-11-04 (https://elevenlabs.io/docs/api-reference/music/compose):

- `POST {region}/v1/music?output_format=mp3_44100_128`, the region's base URL as Voice Lab uses it, with `xi-api-key`,
  `Content-Type: application/json` and `Accept: audio/mpeg`.
- Body: `prompt`, `music_length_ms` (the API accepts 3,000–600,000; VoxClip sends the clip's length in whole seconds,
  3 s to 5 min), `model_id: "music_v1"` (the default) and `force_instrumental: true` (only valid with `prompt`).
- The reply body is the audio file in `output_format`; a 422 carries `detail[].msg`, which VoxClip shows.

Price: $0.15 per minute on every plan (https://elevenlabs.io/pricing/api, checked 2026-11-04), catalog row
`elevenlabs` / `musicCompose` / `music_v1`, `perMinute` "0.15". **For the lead to verify:** the same page's FAQ also says
"Music and Sound Effects are billed per generation", and "commercial use licensing" applies to Starter plans and up.

The suggestion prices a track without sending anything (`ElevenMusicClient.quote`). The row's "Make · $0.11" button
carries the price and the line under it says what is sent ("Sends this prompt to ElevenLabs for a 42 s instrumental:
…"); that click is the approval. A quote is used once and goes stale after 10 minutes. The request is sent once and
never retried; the spend ledger records the estimate when the provider accepts it (a 2xx status), as Voice Lab does.
Without an ElevenLabs key the section says "Add an ElevenLabs key in Settings to make music for this clip." and offers
no generated row.

### 3.3 Your music

The Music folder setting is the Mac preference `VoxClipMusicFolder`; without it, `~/Music/VoxClip` when that folder
exists. The section lists its MP3, M4A, WAV and AIFF files (not subfolders, at most 200). "Add a file…" opens the system
file picker for the same types.

### 3.4 Suggestions

`MusicSuggestionService` (Media) implements `MusicSuggesting` (Core):
`candidates(for: MusicBrief, clipSeconds:) async -> MusicSuggestionResult`. A brief has a mood, optional search words,
an optional Eleven Music prompt and a reason; the autopilot planner's music suggestion (title, mood, prompt, reason)
maps onto it. The result is at most one candidate per source, ordered library, generated, file: the best library match,
one priced generation not yet made, and the user's own file when one shares a word of three or more letters with the
brief. A source that cannot answer (offline, rate-limited, no key) adds a note and never hides the others. The App's
`MusicPanel.suggest(_:model:)` is the entry point for Claude's suggestion (`settled()` waits for it); the search field
calls it with the user's words.

## 4. Mix

The composition builder renders the bed (`MusicBedRenderer`) and adds it as a second audio track, so preview and export
play the same mix:

1. **Speech activity** comes from the clip's final voice audio (the composition's voice track, with any Voice Lab
   phrases already mixed in), read at 48 kHz mono in 10 ms frames. A frame is speech when its RMS is at least
   max(−50 dBFS, the 90th percentile − 25 dB). Runs shorter than 50 ms are dropped and pauses shorter than 250 ms are
   bridged.
2. **Level.** The bed sits `gainDb` (−20 by default) under the speech: gain = speech + gainDb − music, where speech is
   the power mean of the speech frames (−20 dBFS when there is none) and music is the power mean of the track's
   audible frames, measured per channel. The gain is at most +12 dB and at least −60 dB.
3. **Ducking** (when on): −12 dB, linear in dB, reached by each speech onset (the 150 ms attack starts early, since the
   whole clip is known) and released over 400 ms after speech ends.
4. **Fades**: linear, 0.5 s in from silence and 1.5 s out to silence by default.
5. **Trim or loop**: from `startOffsetSeconds`, trimmed when the track is long enough; otherwise looped from the track's
   start with equal-power crossfades of up to 1 s (a quarter of a short track).

The bed is a 48 kHz stereo float CAF in the render's scratch folder, kept by a lease while a player or reader uses it.
Without music nothing changes: no second track, the same audio mix, so every golden and bit-exact test is unchanged.
The edited-audio path (word and speaker checks) and the video-duration probe always read the voice alone.

## 5. Credits

`ProjectMusic.creditLine`: CC BY and the other library licences use Openverse's attribution ("Music: " + attribution),
or "Music: “title” by creator (CC0) <url>" when there is none; generated tracks read "Music: “title”, made with Eleven
Music."; own files need no line. The Export job's post text for a target appends its track's line once, on its own line
(`MusicCredits.postText`); the user can edit around it.

## 6. Interface (Mac)

The Music section sits under the Captions panel's property rows, in their look: an uppercase MUSIC heading (with Remove
while a track is in use), the rows, the search field and Add a file…, then Volume while a track is in use.

- Each row: ▶ (■ while playing; it stops the editor's playback and any other row), the title with the creator, reason
  and length, a source badge (CC BY, CC0, PD, Eleven, Yours) and Use. A generation not yet made has no ▶ and a
  "Make · $x" button with its "Sends this prompt…" line. The track in use is the first row, marked Using, and ▶ plays the
  stored file.
- Without suggestions the rows are the Music folder's first three files; with neither, "Search for music, or add a file
  of your own." Notes from the sources show under the rows.
- One Volume slider, −40 to 0 dB in half-dB steps, applied when the drag ends.
- The footer always names the next step: "Next: ▶ to listen, then Use.", "Next: search, or add a file.", "It dips
  while you talk and fades out at the end. Next: Export. The credit goes in the post text." A failure shows inline with
  Dismiss and "Nothing was changed. Try another track, or try this one again."
- No sheets or alerts; Add a file… uses the system file picker (listed in the pop-up inventory).
- Every change (Use, Remove, Volume) goes through the editor's undoable replace and reloads the preview.

The timeline's M1 lane, below FX, draws the track across the clip with ramps for its fades and "♪ title · −20 dB · dips
under voice"; empty, it reads "Add music in Captions". The M1 header's ♪ button opens the Captions panel.

## 7. Tests

- Core: `MusicProjectWireTests` (shared vectors, v1–3 refusal, v4 promotion, clip pruning, credits),
  `MusicMixTests` (ducking envelope, interpolation, activity, levels, bed gain, fades, trims and loops, Eleven Music
  pricing, briefs).
- Media: `OpenverseMusicClientTests` (the request, licence filtering, ranking and caching, Retry-After and doubling
  back-off, downloads), `ElevenMusicClientTests` (request shape, pricing and bounds, one send with the ledger, refused
  reuse, no retry or charge on failure, stale and keyless quotes), `MusicSuggestionServiceTests`, and `MusicBedTests`
  (−20 dB under speech and −12 dB ducking measured on decoded audio, attack and release, fades, crossfaded loops, a
  voice-only graph without music, and the smoke: a library track found and downloaded through stubs, stored, exported
  under the voice, with its credit in the post text and the edited audio unchanged).
- App: `MusicPanelTests` (folder listing and footers, badges and the priced Make, ▶ stopping playback, Use with the
  credit, volume, Remove and M1, an inline failure sent once) and the timeline's five-track tests.
- Windows Core: `MusicProjectWireTests`.

All audio in tests is synthetic (tones and seeded noise); no test downloads music or calls a provider.

## 8. Windows and what is owed

- Windows Core reads, validates and saves `music` unchanged, prunes a removed clip's track, and stops rendering or
  exporting a project with music: "Windows cannot mix background music into exports yet. Export this project on a Mac,
  or remove its music there. Your music and edits are unchanged." Windows owes the mix, the sources and the UI.
- The default timeline height (216 pt) ends just above M1; the lane is reached with the timeline's vertical scroll or a
  taller timeline.
- Openverse previews stream from the track's host when ▶ is pressed; only Use downloads.
