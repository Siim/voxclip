# macOS Rewrite duration hooks

Production Rewrite generation and every scoped take plan attach the same staged-project request preparer. It builds edit state and pauses from the proposed project, not the live editor or its cached plan. The requested full/clip output scope is explicit. The existing editor render factory binds that snapshot to the canonical Voice Lab data root, source identity, captions, motion and Context Demo inputs. A changed project, source, transcript or output scope fails closed.

The hook supplies a request, not proof of rendering support. `VideoDurationRenderReadiness` still awaits the real `CompositionBuilder`, verifies the exact project/scope contract, and retains the prepared graph. Final acceptance repeats publication/currentness and concrete preparation. A removed paid asset cannot be authorized by an earlier successful readiness result.

No passage starts with a selected or remembered duration mode. Source-duration acceptance still requires a verified silence-only fit; changed-duration acceptance preserves natural audio and the bounded source-video-only zoom-cover recipe. Speech QA, pre-payment minimum speech, provider consent and spending approvals are unchanged.

Acceptance records every selected QA-passing passage, including a changed-duration take that cannot fit the original window. All selected passages and pending free cuts/corrections commit through the existing single project-snapshot undo transaction. One Undo restores the original project and one Redo restores the accepted duration recipes; neither operation changes source transcript timestamps or performs paid work.

The take plan retains already-staged cut IDs without appending them a second time. Its readiness request and final accepted project must have the same serialized edit state, not merely equivalent cut-set geometry.

Dedicated parent-slot verification: `DurationHookIntegrationTests` uses a fake take backend, canonical synthetic media, real production factories, concrete composition readiness and the actual `RewriteSession.acceptTakes` path. It covers full and clip scope, staged cuts/corrections, changed-duration history, missing-asset final-preparation refusal, and source/scope/currentness refusal. These tests require an isolated `VOXCLIP_DATA_DIR`; source authoring alone is not a passing test result.
