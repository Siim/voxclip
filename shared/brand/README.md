# VoxClip brand

VoxConvo's waveform mark, cut: four bars split where the loudest one was, with a coral seam where the two halves join. It shows the one thing VoxClip does, removing a piece of speech and closing the gap, drawn the way the app's timeline draws a cut in edited time (a thin red seam).

## Colours

| Role | Hex | Source |
|---|---|---|
| Plate (macOS, graphite gradient) | `#2C2E35` → `#0F1013` | VoxConvo ink and card surfaces |
| Tile (Windows) | `#2C2E35` → `#121317` | as above; `#121317` is `bg.surface` dark |
| Plate of the hinted 16–64 px sizes | `#2E3037` → `#15161A` | a little lighter, so the edge holds on dark taskbars and Docks |
| Bars (paper) | `#F3F0E7`, gradient `#FBF9F3` → `#E3E0D6` in the masters | VoxConvo `--paper`, `text.primary` dark |
| Seam (coral) | `#F38F83`, gradient `#FFA396` → `#EE6A5E` in the masters | VoxConvo destructive, `cut.stroke` dark |
| Ink (mark and wordmark on light backgrounds) | `#131419` | `text.primary` light |
| Seam on light backgrounds (wordmark) | `#C4453F` | `cut.stroke` light |

Graphite, paper and coral are the only colours. The icon has no text.

## Files

| File | What it is |
|---|---|
| `voxclip-icon.svg` | macOS master on a 1024 artboard. Apple's icon grid: an 824 × 824 body at 100,100 with a continuous corner (radius 185.4), the drop shadow inside the 100 px margin, a soft top rim, the glyph lifted with a small shadow. Renders 128 to 1024 px. |
| `voxclip-icon-flat.svg` | Windows master on a 256 artboard: a Fluent-style tile (16 px padding, radius 44), no macOS plate and no outer shadow. Renders 64 to 256 px. It is a tile because an unpackaged `.exe` has one icon for light and dark taskbars, and paper bars alone would vanish on a light one. |
| `hinted/` | Pixel-hinted sources for the small sizes: `voxclip-icon-16/32/64.svg` (macOS) and `voxclip-icon-flat-16/24/32/48.svg` (Windows). Every edge sits on a whole pixel. Render each only at its own size. At 16 px the glyph drops to three bars and a 1 px seam. |
| `voxclip-mark.svg` | Monochrome line mark for menus, About and the README. `currentColor` (black when used as an image). The seam is told apart by shape alone: thinner and taller than the bars. Drawn on a 15 × 16 grid, so it is pixel-exact at 16, 32, 48 and 64 px tall. It is lighter than the icon glyph, like VoxConvo's mark. |

| `icon-composer/bars.svg`, `icon-composer/seam.svg` | Glyph layers for an Icon Composer `.icon` (macOS 26 Liquid Glass, with dark, clear and tinted variants), on Icon Composer's full-bleed 1024 canvas. Set the background to a linear gradient `#2C2E35` → `#0F1013`. |
| `macos/AppIcon.iconset/` | `icon_16x16.png` to `icon_512x512@2x.png` (10 PNGs) |
| `macos/AppIcon.icns` | Built from the iconset with `iconutil` |
| `windows/app.ico` | 16, 24, 32, 48, 64, 128 and 256 px: 32-bit BMP entries below 256, a PNG entry at 256, the Windows SDK layout |

## Using them

- macOS: the app bundle takes `macos/AppIcon.icns` (`CFBundleIconFile` `AppIcon`, [release.md](../../doc/release.md)). For the macOS 26 icon variants, build `AppIcon.icon` in Icon Composer from the `icon-composer/` layers and keep it next to the `.icns`, as [architecture.md](../../doc/architecture.md) describes.
- Windows: `windows/app.ico` is the application icon (`ApplicationIcon`, the window icon, and Velopack's `--icon`, which release.md points at `src\VoxClip.App\Assets\VoxClip.ico`).
- Keep the seam coral and the bars paper on the icons. On light backgrounds the mark and wordmark are ink with a `#C4453F` seam; on dark backgrounds, paper with `#F38F83`. Do not recolour, outline, rotate or add effects.
- Smallest sizes: the icons at 16 px (hinted), the mark at 16 px tall, the wordmark at 20 px tall. Around the wordmark, keep clear space equal to the gap between the mark and the "v".

## Regenerating

The SVGs are generated by [`tools/brand/brand.py`](../../tools/brand/brand.py) from one set of geometry and colours. Change them there and rerun; do not edit the SVGs by hand. If the glyph changes, update the hinted pixel coordinates (`HINTED`, `MARK_*`) in the same script and check the small sizes by eye.

```sh
python3 -m venv /tmp/voxclip-brand-venv
/tmp/voxclip-brand-venv/bin/pip install -r tools/brand/requirements.txt
P=/tmp/voxclip-brand-venv/bin/python
$P -I tools/brand/brand.py svg        # icon, flat, hinted, mark and Icon Composer SVGs (standard library only)
$P -I tools/brand/brand.py wordmark   # voxclip-wordmark.svg from shared/fonts/dm-sans (fonttools, uharfbuzz)
$P -I tools/brand/brand.py render     # iconset PNGs, AppIcon.icns, app.ico and its PNGs
$P -I tools/brand/brand.py all        # all three
```

`render` needs Pillow, `rsvg-convert` (librsvg; ImageMagick's `magick` is the fallback), and `iconutil` on macOS for the `.icns`. It checks every PNG's size and that each `app.ico` entry is the hinted render rather than a rescale.
