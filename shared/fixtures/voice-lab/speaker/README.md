# Speaker parity and English calibration

`vectors.json` holds four PCM16 mono 16 kHz, six-second LibriSpeech test-clean excerpts, Silero voiced ranges (half-open sample indices), 256-dimensional L2-normalized embeddings and every pairwise cosine score. Embedding and score absolute tolerances are 0.0002, with no relative tolerance. The official CPU ONNX model, VAD hashes, preprocessing version and runtime are recorded. Windows should consume the same WAV bytes and voiced-window/feature contract, not infer identity from filenames.

Source and attribution: LibriSpeech (c) 2014 Vassil Panayotov, CC BY 4.0, `https://www.openslr.org/resources/12/test-clean.tar.gz` (SHA-256 `39fde525e59672dc6d1551919b1478f724438a95aa55f874b576be21967e6c23`). Excerpts were decoded from FLAC to WAV and truncated to the first six seconds. This is a modification; no endorsement is implied. The full licence is in root `THIRD_PARTY_NOTICES.md`.

`calibration-en.json` records all 120 selected six-second utterances from 40 speakers, the selection policy, input WAV hashes, the complete empirical score curve, counts and chosen threshold. `calibration-pairs.json` records all 7,140 distinct-utterance pairs, their same-speaker labels and scores. These are calibration data, not held-out evaluation, anti-spoof guarantees, or microphone acceptance. No consent or provider account is represented by these corpus clips.

`features.json` is a separate deterministic numerical vector generated by the independent NumPy feature implementation from `Float(sin(Double(index) * 0.071) * 0.2)` for 48,000 samples. It contains the first and last 80-bin CMN rows; Swift checks them without a model or download.

See `tools/voice-lab/README.md` for regeneration. The real model is 26,530,309 bytes: it is not a small fixture and is not committed. Real-model tests explicitly skip when the local cache is absent; they never download. Estonian calibration and the user's own-voice check on this Mac microphone are owed. A production language without calibrated evidence remains unavailable.
