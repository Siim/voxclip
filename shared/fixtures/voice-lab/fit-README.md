# Voice Lab fit planner vectors

`tools/fixtures/voice-lab/generate_fit.py` is an independent standard-library Python reference for the silence-only fit planner in `doc/spec/voice-lab.md` §8.9.2. `tools/fixtures/voice-lab/generate.py` runs it after the project fixtures, and it writes `fit-cases.json`; running it twice gives byte-identical output. Both Core suites (`VoiceLabFitPlannerTests`) replay every case and check `caseCount`. The schema id is `voxclip-voice-lab-fit-cases/1`. The file holds synthetic takes: word times, patch tokens and 10 ms RMS envelopes as `[level, frames]` runs of exact binary32 values. It contains no provider output, paid asset or media. It is never edited by hand.

Each case's `input` is what the planner receives: `window` (its samples, and its seam kinds `leftKind` and `rightKind`), `incomingSilence` and `outgoingSilence` (a gap seam's lendable silence, a take edge's silence to the window's nearest word, and null at a hard seam), `sourceSampleRate`, `take` (the paid asset's rate and frames, the TTS trims, the aligned `words` and the `envelope`) and `tokens`. Its `expected` is the plan, `exact` or `changedDuration` with the edits, the pad and borrowed samples at each seam, the trims, the window and its times, the output frames and the word times, plus `naturalOut` and `residualSeconds` for `changedDuration`, or a typed `error`. The rules the vectors pin are the §8.9.2 pinned readings; each named case's `note` says what it tests.

- `cases`: 112 named cases in eleven categories, counted in `categories`: pauses (14), limits (8), redistribution (5), seams (12), edges (6), changedDuration (4), rounding (8), residual (9), rates (15), spec15 (7, §15 test 4) and refusals (24). The rates cases put 22.05, 44.1 and 48 kHz assets against 8, 16, 22.05, 44.1 and 48 kHz sources. The residual cases search a one-word take, one frame longer each time, until the rounding residual lands where the case needs it: in a pad, in a trim, or where neither can take it, so the seams borrow more source samples. `round-word-end-clamped` pins the clamp that keeps a word inside `outDuration`. `residual-zero-borrow` pins a zero first borrow. `refuse-word-below-source-sample`, `refuse-word-straddles-source-sample` and `refuse-final-word-clamp-collapse` pin take-timing refusals before a plan is built; the straddling word has a positive rounded span but lasts less than one source sample. `refuse-empty-word-text` pins `alignmentMismatch` for empty aligned text. `round-unity-recipe-half-frame` pins unity asset-grid validation at a half-frame tie where the old duration-ratio check refused the recipe.
- `propertyCases` and `propertyFuzz`: 2,000 random takes from LCG seed 20261027 (Knuth's MMIX constants), every one committed with its expected plan. A property case leaves out the window and word times, which follow from the integer plan; the suites recompute them. `propertyFuzz` records the seed and the counts of exact, changed-duration and refused plans, longer and shorter takes, edits, borrowing and padding seams, take edges and moved trims. The reference checks every property plan for the voice invariant, the centring and limits of each edit, the seam limits, the word and window times, the §10.5 word rule and the output length, and both Core suites check them again. Source-rate picks now include 8, 16 and 22.05 kHz: 1,617 property inputs and 1,570 results change; replaying all old inputs changes zero results (the zero-borrow guard alone changes none of either property set). Every accepted named and property plan also builds a unity recipe, passes both Core render validators and runs the output planner and render preparation. Exact fits prepare as source video; changed-duration fits prepare as Lip sync. Both Cores' native request capture still refuses non-source video, before any paid snapshot or native work; the placement-chain tests also prepare a Zoom cover recipe and assert this boundary.
- Source-grid seam times: both returned times are their sample divided by the source rate, even for hard and take-end seams that did not borrow. The word clamp uses those returned times. Every exact plan also satisfies `jsRound(outDuration × sourceRate) == windowEndSample − windowStartSample`. Round 4 changes two existing accepted expectations, `seam-times-off-grid` and `seam-times-borrowed`; all 2,000 property expectations stay unchanged. `changed-offgrid-hard-residual-eight` adds the 44.1 kHz source / 24 kHz asset hard/hard probe with an eight-frame residual; raw placed bounds remain 1.5–2.503 s, returned bounds use the source grid.
- `constants`: the §8.3 values the planner reads. Both suites compare them with their own.

Fit-only inputs do not encode the surrounding source. The recipe harness supplies source context for each outer fade half, translating `property-1988` by 61 source samples because its arbitrary window starts inside that half. The placement-chain probes use the actual unmodified window bounds.

Punctuation is judged with the platform's General Category, so the vectors use only scalars whose category every supported Unicode version agrees on.
