# Enrollment order (C7)

`generate_enrollment.py` writes `enrollment-cases.json` from an independent, explicit state table.
No audio, model, key or provider connection is stored in this fixture. The Swift harness constructs
5-second mono PCM16 statements and four distinct 15-second training WAVs at 16 kHz. Its fake embedder
maps positive PCM to `[1, 0]` and negative PCM to `[0, 1]`, at threshold 0.8. Scribe and IVC use a
stub HTTP transport and the existing recorded consent response. Every flow, mutation and journal
case is replayed, plus the attempt-window boundaries. Expected outputs are not generated by Swift.

- `flows`: preparation runs the speaker match without any HTTP. One in-app approval runs plan,
  Scribe, then create. Refused approval, disabled gate and speaker mismatch send nothing; failed
  plan and statement checks stop before the next step. A dispatched creation with an uncertain
  response retains only the remote-operation audit, with no enrollment WAV journal. Successful records retain the full live
  statement, nonce, SHA-256, Scribe evidence, attestations, training hashes and speaker evidence.
- `mutations`: only `same` accepts the combined quote. Each other row changes exactly the named
  binding, including position and role as well as file bytes. Name trimming follows §6.1.
- `attempts`: three recordings at time zero, refused at 599 seconds, allowed at 600 seconds.
  Each new recording runs the speaker check and invalidates earlier prepared plans.
- `recoveries`: a fault after durable verification but before creation simulates process death.
  A new store and client replay the journal. Create is offered again, and still needs a click.
  At 299 seconds the original quote is reused; at 300 it is replaced and needs fresh approval.
  Verification is not sent again. An unsent operation intent is removed without losing the
  verified enrollment. Changed statement bytes, another creator key, dispatch and cancellation
  cannot become a new create. No recovery preparation sends HTTP.

The journal is private local enrollment data, outside project files and the remote-operation
journal. It temporarily retains the exact training WAVs so a restart can recover the approved file
set. Successful creation, cancellation, or dispatch reconciliation removes them. W4 must port the
combined quote and recovery rules and replay this entire table; Windows stays gated until speaker
preprocessing parity is established. No computed floating-point output is stored here.
