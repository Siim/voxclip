# shared/fixtures/captions

Fixtures for the caption system (doc/spec/captions.md section 16). Both apps must pass all of them.

`box-text-colors.json` pins captions §2.3 on both Cores: 54 vectors, comprising every boxed style × all six swatches (36), six defaults and 12 threshold, alpha-preservation and override cases. Each stores the resolved box RGBA, original text T, its WCAG contrast and chosen text RGBA. Regenerate with `python3 -I tools/captions/gen_box_text_colors.py`. Like `card-colors.json`, chosen channels are exact integers; unlike that file, the new vectors also store libm-derived contrast floats, so only this file is listed as tolerant in `tools/captions/check_drift.py` (relative 1e-10, absolute 1e-12, using the existing Voice Lab comparator). All strings, channels and structure remain exact.

The set now has 98 layout cases, 611 pages and 3,673 samples, with 292 layout PNGs plus 38 default gallery PNGs (330 images). The 12 new `box-highlight-{yellow,green,cyan,pink,paper,white}-{portrait,landscape}` cases use the gallery preview words and add 30 PNGs: portrait samples `s0`, `s2`, `s3`, and landscape samples `s0`, `s3`. All use black active text because white fails 4.5:1 on those accents. The original 86 layout cases, all 300 original PNGs and their indexes, the 38 default gallery tiles, `cards.json`, `card-colors.json` and `gallery-samples.json` stay byte-identical; default violet keeps white.

`card-colors.json` pins the design §5.4.3 sidebar key-word contrast rule on both Cores. Regenerate it with `python3 tools/captions/gen_card_colors.py`; do not edit expected values by hand. It covers Paper, Box highlight, exact half-up channels, black/white, the 4.5:1 threshold and different painted backdrops. It is separate so every existing `cards.json` case stays byte-identical.

| File | Format | Contents |
|---|---|---|
| `layout/<case>.json` | `voxclip-caption-layout/1` | Input words, style, frame and project caption settings; expected normalised words with shaping results, pages, lines, word rectangles, boxes, emphasis, emoji, and time samples (active word, states, animation values, reveal, cursor, jitter). Samples with `"golden": true` are rendered as pixel goldens |
| `text-normalization.json` | `voxclip-caption-text/1` | Display text for every punctuation × transform mode, matching keys, sentence and clause flags |
| `math.json` | `voxclip-caption-math/1` | Rounding, easing, mulberry32, jitter keys, blur kernels and rows, rounded-rect paths, gradient end points |
| `preview-tiles.json` | `voxclip-caption-preview/1` | The gallery tile state of every style at 1080×1920 and 1920×1080 |
| `cards.json` | `voxclip-caption-cards/1` | Caption card text for media stand-ins (doc/design.md section 5.4.2): projects, and per case the scope, style and words-hidden switch; expected source, words, key word, line limit per surface, the drawn moment and the fit's word drops |
| `gallery-samples.json` | `voxclip-caption-gallery/1` | Caption gallery tile samples (spec 15.3): projects, and per case the scope, style, playhead and words-hidden switch; expected source, words, duration and tile time |
| `card-colors.json` | `voxclip-caption-card-colors/1` | The design §5.4.3 sidebar key-word colour rule: per case the box colour, the backdrop colour and the expected opaque key-text colour |
| `box-text-colors.json` | `voxclip-caption-box-text-colors/1` | Text on a caption box: style, patch, word state, resolved box, original text, contrast and chosen text |
| `index.json` | `voxclip-caption-index/1` | List of the files above that `gen_fixtures.py` writes |
| `golden/` | PNG + index JSON | Pixel goldens rendered by the macOS renderer (added with the renderers; spec 16.4) |

Everything except `golden/`, `cards.json`, `gallery-samples.json` `card-colors.json` and `box-text-colors.json` is generated by `tools/captions/gen_fixtures.py` from `tools/captions/cases.json`; `card-colors.json` comes from `tools/captions/gen_card_colors.py`, and `box-text-colors.json` from `tools/captions/gen_box_text_colors.py`. `cards.json` is generated by `tools/captions/gen_cards.py` from `tools/captions/card-cases.json`, and `gallery-samples.json` by `tools/captions/gen_gallery.py` from `tools/captions/gallery-cases.json`. See `tools/captions/README.md`. Do not edit expected values by hand: change the spec, the style or the case input, regenerate, and review the diff as a behaviour change. Assertions and tolerances are in spec section 16.3 (layout) and 16.5 (pixels).
