# shared/caption-styles

Caption styles are data. Both apps load these files at run time and render them with one renderer per platform; the rules are in [doc/spec/captions.md](../../doc/spec/captions.md). Owner: the captions spec.

| File | Contents |
|---|---|
| `schema.json` | CaptionStyle v1 (JSON Schema 2020-12). Every `default` in it is normative |
| `styles/<id>.json` | The built-in styles. `id` equals the file name and is stored in project files, so never rename one |
| `casemap.json` | Simple case mappings (Unicode 16.0.0) plus the explicit rules (`ß` → `SS`, Turkish and Azerbaijani dotted i). Generated by `tools/captions/build_casemap.py` |
| `stopwords.json` | Stopwords per language (`en`, `et`) for rule-based emphasis |
| `emoji-keywords.json` | Keyword → emoji per language (`en`, `et`) for the Emoji style; values name PNGs in `shared/fonts/noto-emoji/png128` |

`off` is reserved for "captions off" and is not a style file.

Each style has a `name` (tile label), a `description` (accessibility label), an `order` (gallery position) and a `preview` block: the sample words, which word is active, the reveal progress and a background colour. The gallery renders that frozen moment with animations at rest (spec section 15.3), so every tile shows the style's look rather than a blank animation start.

## Rules for editing

- Validate with `python3 -I tools/captions/check_styles.py` (needs `jsonschema`), then regenerate the fixtures with `tools/captions/gen_fixtures.py` (see `tools/captions/README.md`). A style change is a behaviour change: the fixture diff is reviewed with it.
- Only fonts listed in `shared/fonts/fonts.json` may be referenced. `font.family`, `font.weight` and `font.italic` must equal the manifest values.
- Colours are `#RRGGBB` or `#RRGGBBAA` (straight alpha), or `$accent` / `$accent/AA` when the style defines `accent`. A style with `accent` gets the Colour swatches in Fine tune.
- Users change styles only through the project's merge patch (`captions.overrides`, spec section 2.4); never edit a built-in style to suit one project.
