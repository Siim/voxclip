# shared/fonts

`fonts.json` is generated by `tools/captions/build_font_manifest.py`. It lists every file with its sha256, provenance URL, licence, copyright, vertical metrics (`unitsPerEm`, `hhea`, `os2`, `capHeight`, `xHeight`), `spaceAdvance`, OpenType features and cmap coverage. The apps take metrics and coverage from it, not from the OS.

## Rules

- Static TTF instances only. No variable fonts (`fvar`), no `trak` tables; the manifest builder rejects them.
- Never modify, subset, rename or convert a font. Several carry Reserved Font Names, which forbid distributing modified versions under the same name. Ship each family's `OFL.txt` next to it in the app bundle and list it in About → Licences.
- Only SIL OFL fonts and Apache-2.0 images. No Arial Black or any other proprietary or system font.
- Noto Emoji: the images are taken from the last commit before the repository's root licence changed from Apache-2.0 to OFL-1.1 (2024-07-29); at that commit the README states that the image resources are Apache-2.0. See `tools/captions/font-sources.json`.

## Adding or updating a font

1. Download the static TTF and the family's licence file from google/fonts or the font's official repository, pinned to a commit, into a new folder `shared/fonts/<family>/`. Record the URL and commit in `tools/captions/font-sources.json`.
2. Check the licence text (SIL Open Font License 1.1 or Apache-2.0), the copyright line and any Reserved Font Names.
3. Check coverage: at least Latin Extended including Estonian (õ ä ö ü š ž); styles fall back to Noto Sans for the rest.
4. Run `build_font_manifest.py`, `check_styles.py` and `gen_fixtures.py`, and add the family to the "Fonts" section of `THIRD_PARTY_NOTICES.md`.
